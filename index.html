B.Tech Minor Project · 7th Sem (2026-27) · Team of 3

Secure Voice Using 6D Hyper-Chaotic Encryption on STM32H7

Built a real-time speech encryption scheme using a 6D hyperchaotic PRNG (RK4) and frame-based dynamic S-boxes (Fisher-Yates shuffle) for 16-bit, 32 kHz audio. Implemented the firmware in Embedded C on an STM32H755ZIQ Nucleo board via STM32CubeIDE/MX and verified results with Python over UART (230.4 kbps).
